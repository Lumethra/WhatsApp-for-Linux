# WhatsApp Desktop for Linux (Fedora x Hyprland)

A simple, native WhatsApp desktop client for Linux, designed for Fedora and Hyprland environments. Built with Rust, GTK, and WebKit2GTK, it provides a seamless WhatsApp Web experience with native notifications and desktop integration.

## Features

- Native WhatsApp Web experience
- Desktop notifications (using `notify-rust`)
- Custom user agent for compatibility
- Optimized for Fedora and Hyprland
- Lightweight and fast

## Installation

### Prerequisites
- Fedora Linux (other distros may work)
- Hyprland (recommended, but not required)
- Rust toolchain (`cargo`)
- GTK 3 and WebKit2GTK libraries

### Install dependencies (Fedora)
```sh
sudo dnf install gtk3 webkit2gtk3-devel
```

### Build and Run
```sh
git clone https://github.com/yourusername/whatsapp-linux.git
cd whatsapp-linux
cargo run
```

## Usage

1. Launch the app: `cargo run`.
2. Scan the QR code with your phone to log in.
3. Enjoy WhatsApp with native notifications and integration!
